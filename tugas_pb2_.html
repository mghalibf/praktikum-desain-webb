Profil Kampus

Universitas Muhammadiyah Sidoarjo merupakan perguruan tinggi yang menyediakan berbagai program pendidikan.

Program Sarjana

Universitas Muhammadiyah Sidoarjo memiliki berbagai program studi sarjana, antara lain:

  • Fakultas Agama Islam
  • Fakultas Bisnis, Hukum dan Ilmu Sosial
  • Fakultas Ilmu Kesehatan
  • Fakultas Psikologi dan Ilmu Pendidikan
  • Fakultas Sains dan Teknologi
  • Fakultas Kedokteran

Program Magister (S2)

Program pascasarjana menyediakan pendidikan lanjutan untuk mengembangkan pengetahuan dan keterampilan mahasiswa.

  • Program Magister Manajemen
  • Program Magister Pendidikan Islam
